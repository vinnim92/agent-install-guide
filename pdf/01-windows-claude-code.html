版本 v3.2.0|Windows 10/11

适用对象

本手册适合Windows 用户。如果你平时只用鼠标操作电脑，本手册会手把手带你完成安装。

本安装包已内置安装脚本，不需要从 GitHub 复制远程命令。但安装过程中仍需要网络，用于下载 Agent 工具和相关依赖。
Claude Code 不需要安装 Node.js — 它自带运行时，装上就能用。本手册默认采用 DeepSeek API 方案（国内获取方便、价格便宜）。

安装前准备

🔑 需要准备一个 DeepSeek API Key

获取地址：platform.deepseek.com（在浏览器打开）
用手机号注册 → 点左侧"API Keys" → 创建 Key（以 sk- 开头）。

💻 系统要求

Windows 10 或 Windows 11

🌐 需要网络连接

安装过程需要联网下载。如果公司/学校网络较严，切换到手机热点。

第一步：解压安装包

1

找到下载的 zip 文件

文件名：AI-Agent-Windows-小白安装包-v3.2.0.zip

2

右键点击 zip → "全部解压缩"

选择一个你方便找到的位置，如"桌面"。

3

打开解压后的文件夹

能看到 windows 文件夹和几个说明文件。

不要在压缩包预览中直接运行！请先完整解压，否则脚本可能无法正常工作。

第二步：双击运行安装

1

打开 windows 文件夹

2

双击 install-claude.cmd

会弹出一个黑色窗口，标题栏显示"Claude Code 小白安装器"。

3

如果弹出 Windows 安全提示

点击"仍要运行"或"更多信息 → 仍要运行"。

⚠️ 重要：安装过程中窗口会显示文字输出，这是正常的。不要中途关闭窗口。
关于 "Windows 已保护你的电脑" 提示：这是因为脚本来自互联网。本安装包完全开源，代码可查看。点击"更多信息"然后"仍要运行"即可。

第三步：跟着提示操作

安装脚本会自动检查你的电脑环境并安装 Claude Code：

  1. 脚本显示 "正在检查你的电脑环境…"
  2. 检查系统、网络、是否已安装过 Claude Code
  3. 自动下载并安装 Claude Code（自带运行时，不需要 Node.js）
  4. 看到 "✅ Claude Code 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。截图完整窗口（含命令和报错文字），然后访问故障排查页面或联系技术支持。

第四步：配置 DeepSeek API

安装完成后，脚本会自动询问你是否配置 DeepSeek API。

1

看到 "是否现在配置 DeepSeek API？" 时，输入 y 回车

2

粘贴你的 DeepSeek API Key（以 sk- 开头），回车

输入时不会显示字符是正常的，粘贴后直接回车即可。

3

看到 "✅ DeepSeek API 配置完成"

💡 如果没有 DeepSeek API Key：可以跳过此步骤。如果你已有 Claude 官方账号，也可以稍后运行 claude login 登录。

怎么知道安装成功了？

  • 关闭当前窗口，重新打开 PowerShell 或命令提示符
  • 输入 claude --version，能看到版本号
  • 输入 claude 能进入对话界面

常见问题

Q: 双击 .cmd 一闪而过？

A: 不要在压缩包预览中双击。请先完整解压 zip，再打开文件夹运行。

Q: Windows 弹出 "已保护你的电脑"？

A: 点击"更多信息"，然后点击"仍要运行"。本安装包开源安全，可以放心运行。

Q: 需要安装 Node.js 吗？

A: 不需要。Claude Code 自带运行时，不需要单独安装 Node.js。

Q: 在哪里获取 DeepSeek API Key？

A: 浏览器打开 platform.deepseek.com，手机号注册后创建 API Key。

Q: 安装后输入 claude 提示"找不到命令"？

A: 关闭当前 PowerShell 窗口，重新打开一个新的即可。如果仍有问题，重新运行一遍安装脚本。

Q: 安装失败怎么办？

A: 打开故障排查页面：
https://vinnim92.github.io/agent-install-guide/troubleshooting.html
