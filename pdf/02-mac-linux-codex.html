macOS / Linux 小白安装手册

OpenAI 出品 · 本地脚本一键安装

版本 v3.2.6|macOS / Linux

适用对象

本手册适合macOS 和 Linux 用户。如果你平时只用鼠标操作电脑，从没打开过"终端"，本手册会手把手带你完成安装。

本安装包已内置安装脚本，不需要从 GitHub 复制远程命令。但安装过程中仍需要网络，用于下载 Node.js、Codex 和相关依赖。
安装脚本会自动检测并安装 Node.js — 你不需要手动安装任何依赖。

安装前准备

🎫 登录方式二选一

方式一：ChatGPT 官方账号登录（Plus / Pro / Team 订阅）
方式二：OpenAI API Key 登录（按量计费）。

💻 系统要求

macOS 10.15+ 或 Linux

🌐 需要网络连接

安装过程需要联网下载 Node.js 和 Codex。

第一步：解压安装包

1

找到下载的 zip 文件

文件名：AI-Agent-macOS-Linux-小白安装包-v3.2.6.zip

2

双击解压

Mac 上双击 zip 即可解压到当前文件夹。

3

记住解压位置

第二步：打开终端，进入安装目录

1

打开终端

按 Command + 空格，输入"终端"，回车。

2

进入 mac-linux 文件夹

在终端输入 cd ，然后把 mac-linux 文件夹拖到终端窗口，回车。

💡 拖拽技巧：直接把文件夹图标拖进终端窗口，会自动填入完整路径。

第三步：运行安装脚本

在终端中粘贴以下命令，回车：

bash install-codex.sh
⚠️ 如果提示 "Permission denied"：先运行 chmod +x install-codex.sh。
💡 想跳过确认自动安装？运行：AGENT_INSTALL_YES=1 bash install-codex.sh

第四步：跟着提示操作

  1. 脚本显示 "正在检查你的电脑环境…"
  2. 自动检查 Node.js，如未安装会自动帮你安装
  3. 脚本通过官方渠道自动安装 Codex
  4. 看到 "✅ Codex 安装成功" 就完成了

第五步：登录 Codex

官方账号登录：在终端输入 codex login，浏览器会自动弹出 OpenAI 登录页面。
API Key 登录：设置环境变量 OPENAI_API_KEY。

怎么知道安装成功了？

  • 关闭终端，重新打开
  • 输入 codex --version，能看到版本号
  • 输入 codex 能进入对话界面

为什么这版安装包更稳定？

✅ 本地脚本包，不依赖远程入口

安装脚本已内置在 zip 包中，不需要复制远程命令或访问 GitHub Pages/jsDelivr。

✅ 拖拽进终端即可

不需要手动输入长路径。把文件夹拖进终端窗口就能自动填入路径。

✅ 自动确认模式

默认支持 AGENT_INSTALL_YES=1 自动确认。

常见问题

Q: 安装后输入 codex 提示"找不到命令"？

A: 关闭终端重新打开即可。如果仍有问题，重新运行一遍安装脚本。

Q: 没有 ChatGPT 账号怎么办？

A: 可以使用 OpenAI API Key 登录。在 platform.openai.com 注册并创建 API Key。

Q: 权限错误 Permission denied？

A: 运行 chmod +x install-codex.sh，然后再运行安装命令。

Q: 安装失败怎么办？

A: 打开故障排查页面：
https://vinnim92.github.io/agent-install-guide/troubleshooting.html
