macOS / Linux 小白安装手册

Anthropic 出品 · DeepSeek API 优先 · 本地脚本一键安装

版本 v3.2.3|macOS / Linux

适用对象

本手册适合macOS 和 Linux 用户。如果你平时只用鼠标操作电脑，从没打开过"终端"，本手册会手把手带你完成安装。

本安装包已内置安装脚本，不需要从 GitHub 复制远程命令。但安装过程中仍需要网络，用于下载 Agent 工具和相关依赖。
Claude Code 不需要安装 Node.js — 它自带运行时，装上就能用。本手册默认采用 DeepSeek API 方案（国内获取方便、价格便宜）。

安装前准备

🔑 需要准备一个 DeepSeek API Key

获取地址：platform.deepseek.com（在浏览器打开）
用手机号注册 → 点左侧"API Keys" → 创建 Key（以 sk- 开头）。

💻 系统要求

macOS 10.15+ 或 Linux

🌐 需要网络连接

安装过程需要联网下载。如果公司/学校网络较严，切换到手机热点。

第一步：解压安装包

1

找到下载的 zip 文件

文件名：AI-Agent-macOS-Linux-小白安装包-v3.2.3.zip

2

双击解压

Mac 上双击 zip 即可解压到当前文件夹。

3

记住解压位置

解压后会得到一个文件夹，记住它的位置。

第二步：打开终端，进入安装目录

1

打开终端

按 Command + 空格，输入"终端"，回车。

2

进入 mac-linux 文件夹

在终端输入 cd （cd 后面有个空格），然后把 mac-linux 文件夹拖到终端窗口，回车。

💡 拖拽技巧：直接把文件夹图标拖进终端窗口，会自动填入完整路径，不需要手动敲。

第三步：运行安装脚本

在终端中粘贴以下命令，回车：

bash install-claude-code.sh

脚本会自动检查环境并安装 Claude Code。

⚠️ 如果提示 "Permission denied"：先运行 chmod +x install-claude-code.sh，然后再 bash install-claude-code.sh。
💡 想跳过确认自动安装？运行：AGENT_INSTALL_YES=1 bash install-claude-code.sh

第四步：跟着提示操作

  1. 脚本显示 "正在检查你的电脑环境…"
  2. 检查系统、网络、是否已安装过 Claude Code
  3. 自动下载并安装 Claude Code（自带运行时）
  4. 看到 "✅ Claude Code 安装成功" 就完成了
💡 如果中途出现红色报错：截图完整终端窗口，然后访问故障排查页面或联系技术支持。

第五步：配置 DeepSeek API

安装完成后，脚本会自动询问是否配置 DeepSeek API。输入 y 并粘贴你的 API Key 即可。

怎么知道安装成功了？

  • 关闭终端，重新打开
  • 输入 claude --version，能看到版本号
  • 输入 claude 能进入对话界面

为什么这版安装包更稳定？

✅ 本地脚本包，不依赖远程入口

安装脚本已内置在 zip 包中，不需要复制远程命令或访问 GitHub Pages/jsDelivr。

✅ 拖拽进终端即可

不需要手动输入长路径。把文件夹拖进终端窗口就能自动填入路径。

常见问题

Q: 安装后输入 claude 提示"找不到命令"？

A: 关闭终端重新打开即可。如果仍有问题，重新运行一遍安装脚本。

Q: 需要安装 Node.js 吗？

A: 不需要。Claude Code 自带运行时。

Q: 在哪里获取 DeepSeek API Key？

A: 浏览器打开 platform.deepseek.com，手机号注册后创建 API Key。

Q: 权限错误 Permission denied？

A: 运行 chmod +x install-claude-code.sh，然后再运行安装命令。

Q: 安装失败怎么办？

A: 打开故障排查页面：
https://vinnim92.github.io/agent-install-guide/troubleshooting.html
