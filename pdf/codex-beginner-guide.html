小白安装手册

OpenAI 出品 · 命令行 AI 编程助手

版本 v3.1.1|支持 Windows / Mac

适用对象

本手册适合第一次接触命令行的新手用户。如果你平时只用鼠标操作电脑，从没打开过"终端"或"PowerShell"，本手册会手把手带你完成安装。

✅ 安装脚本会自动检测并安装 Node.js — 你不需要手动安装任何依赖。安装完成后可选择官方账号登录或 API Key 登录。

安装前准备

🎫 登录方式二选一

方式一：ChatGPT 官方账号登录（Plus / Pro / Team 订阅）
方式二：OpenAI API Key 登录（按量计费）。安装完成后脚本会展示两种方式的具体步骤。

💻 电脑系统要求

Windows 10/11 或 macOS 10.15+

🌐 需要网络连接

安装过程需要联网下载 Node.js 和 Codex。如果公司/学校网络较严，切换到手机热点。

第一步：打开终端 / PowerShell

🪟 Windows 用户

1

点击"开始"菜单（屏幕左下角 Windows 图标）

2

在搜索框输入 PowerShell

搜索结果会出现蓝色图标的"Windows PowerShell"。

3

点击打开

弹出一个白底黑字（或蓝底白字）的窗口，能看到闪烁的光标，这就是命令行界面。

💡 提示：你也可以右键点击"开始"菜单 → 选择"Windows 终端"或"PowerShell"。

🍎 Mac 用户

1

点击程序坞（Dock）上的 Launchpad 图标（火箭）

2

在搜索框输入 终端

或者在 Finder 中打开：应用程序 → 实用工具 → 终端.app

3

双击打开"终端"

弹出一个白底黑字的窗口，能看到闪烁的光标和你的用户名。这就是命令行界面。

💡 提示：按 Command + 空格 打开 Spotlight，输入"终端"然后回车，这是最快的方式。

第二步：复制安装命令

⚠️ 重要：请复制整行命令。如果粘贴后变成两行，请删除换行，让它保持一整行。

选中下面 对应你电脑系统 的那行命令，完整复制（用鼠标选中 → 右键复制，或按 Ctrl+C / Command+C）：

🪟 Windows 用户（在 PowerShell 中运行）

Windows PowerShell irm https://vinnim92.github.io/agent-install-guide/i/codex.ps1 | iex

🍎 Mac 用户（在终端中运行）

macOS 终端 curl -fsSL https://vinnim92.github.io/agent-install-guide/i/codex.sh | bash
📌 关于这条短命令：这条短命令会自动获取最新稳定版安装脚本，普通用户不需要关心版本号。如果 CDN 暂时访问失败，脚本会自动尝试备用下载地址。
💡 Mac 命令中的 AGENT_INSTALL_YES=1：脚本会自动检查电脑环境。为了避免命令行管道读取不到键盘输入，交付命令默认使用自动确认模式。如果想手动确认每一步，可以先下载脚本再运行：curl -fsSL "..." -o codex.sh && bash codex.sh

第三步：粘贴命令，按回车

1

把刚才复制的命令粘贴到终端窗口

Windows PowerShell：直接右键点击窗口即可粘贴（或按 Ctrl+V）。
Mac 终端：按 Command+V 粘贴。

2

按键盘上的 Enter / Return 回车键

命令开始运行。你会看到一些文字输出，这是正常的。

💡 如果粘贴不了：试试右键 → 粘贴，或者 Shift+Insert（Windows）。如果还是不行，检查确认复制时真的选中了整行命令。

第四步：跟着提示操作

安装脚本会自动检查你的电脑环境并安装 Codex：

  1. 脚本会显示 "正在检查你的电脑环境…"
  2. 自动检查 Node.js，如未安装会自动帮你安装
  3. 确认提示会自动跳过（AGENT_INSTALL_YES=1 模式），脚本直接进入安装
  4. 脚本通过官方渠道自动安装 Codex
  5. 看到 "✅ Codex 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。把错误截图保存下来，然后访问故障排查页面：
https://vinnim92.github.io/agent-install-guide/troubleshooting.html

第五步：登录 Codex

安装完成后，你需要在终端运行一次登录命令。脚本会在安装结束时提示你：

🔑 选择登录方式

官方账号登录：在终端输入 codex login，浏览器会自动弹出 OpenAI 登录页面。
API Key 登录：设置环境变量 OPENAI_API_KEY 为你的 API Key。

💡 安装脚本完成后会直接展示登录命令，照着输入即可。

怎么知道安装成功了？

  • 在终端输入 codex --version，能看到版本号
  • 输入 codex 能进入对话界面
  • 启动命令是 codex

常见问题

Q: 关闭终端重开后，输入 codex 提示"找不到命令"？

A: 重新运行一遍安装脚本即可，它会自动识别已有安装并修复 PATH。

Q: 没有 ChatGPT 账号怎么办？

A: 可以使用 OpenAI API Key 登录。在 platform.openai.com 注册并创建 API Key，按量计费。

Q: 官方脚本下载失败怎么办？

A: 安装脚本会自动切换到 npm fallback。如果两种方式都失败，访问故障排查页面检查网络。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://vinnim92.github.io/agent-install-guide/troubleshooting.html

安装好了，接下来做什么？

  1. 在终端输入 codex 启动对话
  2. 试试问它："帮我写一个 Python 爬虫脚本"
  3. 用 codex "分析这个项目" 让 Codex 理解你当前目录的代码
  4. 探索更多功能：codex --help 查看所有可用命令

安全说明

  • 脚本只安装 Codex，不会多装其他东西
  • 脚本支持 --dry-run 预演，安装前可以先看清楚每一步
  • 涉及环境修改时会提示你确认
  • 所有脚本在 GitHub 开源，代码随时可查看
