小白安装手册

OpenAI 出品 · 命令行 AI 编程助手

版本 v3.0.4|支持 Windows / Mac

适用对象

本手册适合第一次接触命令行的新手用户。如果你平时只用鼠标操作电脑，从没打开过"终端"或"PowerShell"，本手册会手把手带你完成安装。

✅ 安装脚本会自动检测并安装 Node.js — 你不需要手动安装任何依赖。但你需要一个 ChatGPT 账号（Plus / Pro / Team）或 OpenAI API Key。

安装前准备

🎫 需要一个 ChatGPT 账号

注册地址：https://chatgpt.com（在浏览器打开）
需要 Plus（推荐）、Pro 或 Team 订阅。或者准备一个 OpenAI API Key。

💻 电脑系统要求

Windows 10/11 或 macOS 10.15+

🌐 需要网络连接

安装过程需要联网下载 Node.js 和 Codex。如果公司/学校网络较严，切换到手机热点。

第一步：打开终端 / PowerShell

🪟 Windows 用户

1

点击"开始"菜单（屏幕左下角 Windows 图标）

2

在搜索框输入 PowerShell

搜索结果会出现蓝色图标的"Windows PowerShell"。

3

点击打开

弹出一个白底黑字（或蓝底白字）的窗口，能看到闪烁的光标，这就是命令行界面。

💡 提示：你也可以右键点击"开始"菜单 → 选择"Windows 终端"或"PowerShell"。

🍎 Mac 用户

1

点击程序坞（Dock）上的 Launchpad 图标（火箭）

2

在搜索框输入 终端

或者在 Finder 中打开：应用程序 → 实用工具 → 终端.app

3

双击打开"终端"

弹出一个白底黑字的窗口，能看到闪烁的光标和你的用户名。这就是命令行界面。

💡 提示：按 Command + 空格 打开 Spotlight，输入"终端"然后回车，这是最快的方式。

第二步：复制安装命令

选中下面 对应你电脑系统 的那行命令，完整复制（用鼠标选中 → 右键复制，或按 Ctrl+C / Command+C）：

🪟 Windows 用户（在 PowerShell 中运行）

Windows PowerShell iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.4/scripts/install-codex.ps1 | iex

🍎 Mac 用户（在终端中运行）

macOS 终端 curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.4/scripts/install-codex.sh | bash
⚠️ 注意：请完整复制整行命令，不要手动输入（容易打错字母）。不要漏掉开头的 iwr（Windows）或 curl（Mac）。

第三步：粘贴命令，按回车

1

把刚才复制的命令粘贴到终端窗口

Windows PowerShell：直接右键点击窗口即可粘贴（或按 Ctrl+V）。
Mac 终端：按 Command+V 粘贴。

2

按键盘上的 Enter / Return 回车键

命令开始运行。你会看到一些文字输出，这是正常的。

💡 如果粘贴不了：试试右键 → 粘贴，或者 Shift+Insert（Windows）。如果还是不行，检查确认复制时真的选中了整行命令。

第四步：跟着提示操作

安装脚本会自动检查你的电脑环境，如果需要还会自动安装 Node.js：

  1. 脚本会显示 "正在检查你的电脑环境…"
  2. 检查系统、网络、Node.js 版本、是否已安装过 Codex
  3. 如果 Node.js 版本不够，脚本会询问是否自动安装 → 输入 y 回车
  4. 显示 "是否继续安装 Codex？" → 输入 y 回车
  5. 脚本通过官方渠道自动安装 Codex
  6. 看到 "✅ Codex 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。把错误截图保存下来，然后访问故障排查页面：
https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.4/docs/support.html

第五步：启动 Codex

安装完成后，关掉当前的终端/PowerShell 窗口，重新打开一个新窗口，然后：

在终端 / PowerShell 中输入 codex

第一次运行会自动弹出浏览器，让你登录 ChatGPT 账号。登录后回到终端就能开始对话了。

💡 常用命令：
codex — 开始交互式对话
codex "你的任务" — 带初始提示启动
codex exec "..." — 非交互执行任务
codex --version — 查看版本
codex login — 手动登录

怎么知道安装成功了？

  • 在终端输入 codex --version，能看到版本号
  • 输入 codex 能进入对话界面
  • 浏览器弹出 ChatGPT 登录页，登录后能正常对话

常见问题

Q: 关闭终端重开后，输入 codex 提示"找不到命令"？

A: 重新运行一遍安装脚本即可，它会自动识别已有安装并修复 PATH。

Q: 安装脚本提示 Node.js 安装失败？

A: 手动去 https://nodejs.org 下载并安装 LTS 版本（左侧绿色按钮），装完后再运行一次 Codex 安装脚本。

Q: 登录时浏览器没有自动弹出？

A: 在终端手动输入 codex login，会触发浏览器登录流程。

Q: 提示"未授权"或"需要订阅"？

A: Codex CLI 需要 ChatGPT Plus/Pro/Team 账号。免费版 ChatGPT 无法使用 Codex。确认你的订阅状态后在 codex 中重新登录。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.4/docs/support.html

安装好了，接下来做什么？

  1. 在终端输入 codex 启动对话
  2. 试试问它："帮我写一个 Python 的 Hello World 程序"
  3. 用 codex "解释我当前目录的代码" 让它分析项目
  4. 探索更多功能：codex --help 查看所有可用命令
