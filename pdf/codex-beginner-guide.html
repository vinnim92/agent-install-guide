小白安装手册

OpenAI 出品 · 命令行 AI 编程助手

版本 v3.1.0|支持 Windows / Mac

适用对象

本手册适合第一次接触命令行的新手用户。如果你平时只用鼠标操作电脑，从没打开过"终端"或"PowerShell"，本手册会手把手带你完成安装。

✅ 安装脚本会自动检测并安装 Node.js — 你不需要手动安装任何依赖。安装完成后可选择官方账号登录或 API Key 登录。

安装前准备

🎫 登录方式二选一

方式一：ChatGPT 官方账号登录（Plus / Pro / Team 订阅）
方式二：OpenAI API Key 登录（按量计费）。安装完成后脚本会展示两种方式的具体步骤。

💻 电脑系统要求

Windows 10/11 或 macOS 10.15+

🌐 需要网络连接

安装过程需要联网下载 Node.js 和 Codex。如果公司/学校网络较严，切换到手机热点。

第一步：打开终端 / PowerShell

🪟 Windows 用户

1

点击"开始"菜单（屏幕左下角 Windows 图标）

2

在搜索框输入 PowerShell

搜索结果会出现蓝色图标的"Windows PowerShell"。

3

点击打开

弹出一个白底黑字（或蓝底白字）的窗口，能看到闪烁的光标，这就是命令行界面。

💡 提示：你也可以右键点击"开始"菜单 → 选择"Windows 终端"或"PowerShell"。

🍎 Mac 用户

1

点击程序坞（Dock）上的 Launchpad 图标（火箭）

2

在搜索框输入 终端

或者在 Finder 中打开：应用程序 → 实用工具 → 终端.app

3

双击打开"终端"

弹出一个白底黑字的窗口，能看到闪烁的光标和你的用户名。这就是命令行界面。

💡 提示：按 Command + 空格 打开 Spotlight，输入"终端"然后回车，这是最快的方式。

第二步：复制安装命令

⚠️ 重要提醒：PDF 里的长命令有时会因换行，复制后被拆成两段。
如果你看到命令里出现类似 @v3.0. 和下一行 5/scripts/...，说明命令被拆坏了。
请优先打开交付包里的《06-一键复制命令.txt》，从里面复制完整命令。
正确命令必须是一整行
❌ 错误（被拆断）：
@v3.0.
5/scripts/...
✅ 正确（完整）：
@v3.1.0/scripts/...

选中下面 对应你电脑系统 的那行命令，完整复制（用鼠标选中 → 右键复制，或按 Ctrl+C / Command+C）：

为避免复制断行，请优先从《06-一键复制命令.txt》中复制。

🪟 Windows 用户（在 PowerShell 中运行）

Windows PowerShell irm https://vinnim92.github.io/agent-install-guide/i/codex.ps1 | iex

🍎 Mac 用户（在终端中运行）

macOS 终端 curl -fsSL https://vinnim92.github.io/agent-install-guide/i/codex.sh | bash
💡 Mac 命令中的 AGENT_INSTALL_YES=1：脚本会自动检查电脑环境。为了避免命令行管道读取不到键盘输入，交付命令默认使用自动确认模式。如果想手动确认每一步，可以先下载脚本再运行：curl -fsSL "..." -o install-codex.sh && bash install-codex.sh
⚠️ 注意：请完整复制整行命令，不要手动输入（容易打错字母）。不要漏掉开头的 iwr（Windows）或 curl（Mac）。

第三步：粘贴命令，按回车

1

把刚才复制的命令粘贴到终端窗口

Windows PowerShell：直接右键点击窗口即可粘贴（或按 Ctrl+V）。
Mac 终端：按 Command+V 粘贴。

2

按键盘上的 Enter / Return 回车键

命令开始运行。你会看到一些文字输出，这是正常的。

💡 如果粘贴不了：试试右键 → 粘贴，或者 Shift+Insert（Windows）。如果还是不行，检查确认复制时真的选中了整行命令。

第四步：跟着提示操作

安装脚本会自动检查你的电脑环境，如果需要还会自动安装 Node.js：

  1. 脚本会显示 "正在检查你的电脑环境…"
  2. 检查系统、网络、Node.js 版本、是否已安装过 Codex
  3. 如果 Node.js 版本不够，脚本会询问是否自动安装 → 输入 y 回车
  4. 确认提示会自动跳过（AGENT_INSTALL_YES=1 模式），脚本直接进入安装
  5. 脚本通过官方渠道自动安装 Codex
  6. 看到 "✅ Codex 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。把错误截图保存下来，然后访问故障排查页面：
https://vinnim92.github.io/agent-install-guide/docs/support.html

第五步：登录 Codex

安装完成后，关掉当前的终端/PowerShell 窗口，重新打开一个新窗口，选择以下任一方式登录：

方式一：官方账号登录

适合已有 ChatGPT / OpenAI 账号的用户。

在终端 / PowerShell 中输入 codex login

浏览器会自动弹出 ChatGPT 登录页，登录后回到终端即可使用。

方式二：API Key 登录

适合使用 OpenAI API Key 的用户。

macOS / Linux 终端 export OPENAI_API_KEY="你的 OpenAI API Key" printenv OPENAI_API_KEY | codex login --with-api-key
Windows PowerShell $env:OPENAI_API_KEY="你的 OpenAI API Key" $env:OPENAI_API_KEY | codex login --with-api-key
💡 常用命令：
codex — 开始交互式对话
codex "你的任务" — 带初始提示启动
codex exec "..." — 非交互执行任务
codex --version — 查看版本
codex login — 手动登录

怎么知道安装成功了？

  • 在终端输入 codex --version，能看到版本号
  • 输入 codex 能进入对话界面
  • 完成登录后能正常与 AI 对话

常见问题

Q: 关闭终端重开后，输入 codex 提示"找不到命令"？

A: 重新运行一遍安装脚本即可，它会自动识别已有安装并修复 PATH。

Q: 安装脚本提示 Node.js 安装失败？

A: 手动去 https://nodejs.org 下载并安装 LTS 版本（左侧绿色按钮），装完后再运行一次 Codex 安装脚本。

Q: 登录时浏览器没有自动弹出？

A: 在终端手动输入 codex login，会触发浏览器登录流程。

Q: API Key 方式怎么登录？

A: 先设置环境变量 export OPENAI_API_KEY="你的Key"（Mac）或 $env:OPENAI_API_KEY="你的Key"（Windows），然后运行 printenv OPENAI_API_KEY | codex login --with-api-key（Mac）或 $env:OPENAI_API_KEY | codex login --with-api-key（Windows）。

Q: 提示"未授权"或"需要订阅"？

A: 如果用官方账号登录，需要 ChatGPT Plus/Pro/Team 订阅；如果用 API Key 登录，确认 Key 有效且余额充足。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://vinnim92.github.io/agent-install-guide/docs/support.html

安装好了，接下来做什么？

  1. 在终端输入 codex 启动对话
  2. 试试问它："帮我写一个 Python 的 Hello World 程序"
  3. 用 codex "解释我当前目录的代码" 让它分析项目
  4. 探索更多功能：codex --help 查看所有可用命令
