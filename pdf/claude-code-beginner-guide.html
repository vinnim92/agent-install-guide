小白安装手册

Anthropic 出品 · DeepSeek API 优先 · 命令行 AI 编程助手

版本 v3.0.8|支持 Windows / Mac

适用对象

本手册适合第一次接触命令行的新手用户。如果你平时只用鼠标操作电脑，从没打开过"终端"或"PowerShell"，本手册会手把手带你完成安装。

✅ Claude Code 不需要安装 Node.js — 它自带运行时，装上就能用。本手册默认采用 DeepSeek API 方案（国内获取方便、价格便宜），安装后脚本会引导你配置。

安装前准备

🔑 需要准备一个 DeepSeek API Key

获取地址：platform.deepseek.com（在浏览器打开）
用手机号注册 → 点左侧"API Keys" → 创建 Key（以 sk- 开头）。价格便宜，¥1 起充。

💻 电脑系统要求

Windows 10/11 或 macOS 10.15+

🌐 需要网络连接

安装过程需要联网下载。如果公司/学校网络较严，切换到手机热点。

第一步：打开终端 / PowerShell

🪟 Windows 用户

1

点击"开始"菜单（屏幕左下角 Windows 图标）

2

在搜索框输入 PowerShell

搜索结果会出现蓝色图标的"Windows PowerShell"。

3

点击打开

弹出一个白底黑字（或蓝底白字）的窗口，能看到闪烁的光标，这就是命令行界面。

💡 提示：你也可以右键点击"开始"菜单 → 选择"Windows 终端"或"PowerShell"。

🍎 Mac 用户

1

点击程序坞（Dock）上的 Launchpad 图标（火箭）

2

在搜索框输入 终端

或者在 Finder 中打开：应用程序 → 实用工具 → 终端.app

3

双击打开"终端"

弹出一个白底黑字的窗口，能看到闪烁的光标和你的用户名。这就是命令行界面。

💡 提示：按 Command + 空格 打开 Spotlight，输入"终端"然后回车，这是最快的方式。

第二步：复制安装命令

⚠️ 重要提醒：PDF 里的长命令有时会因换行，复制后被拆成两段。
如果你看到命令里出现类似 @v3.0. 和下一行 5/scripts/...，说明命令被拆坏了。
请优先打开交付包里的《06-一键复制命令.txt》，从里面复制完整命令。
正确命令必须是一整行
❌ 错误（被拆断）：
@v3.0.
5/scripts/...
✅ 正确（完整）：
@v3.0.8/scripts/...

选中下面 对应你电脑系统 的那行命令，完整复制（用鼠标选中 → 右键复制，或按 Ctrl+C / Command+C）：

为避免复制断行，请优先从《06-一键复制命令.txt》中复制。

🪟 Windows 用户（在 PowerShell 中运行）

Windows PowerShell iwr -useb "https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.8/scripts/install-claude-code.ps1" | iex

🍎 Mac 用户（在终端中运行）

macOS 终端 curl -fsSL "https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.8/scripts/install-claude-code.sh" | AGENT_INSTALL_YES=1 bash
💡 Mac 命令中的 AGENT_INSTALL_YES=1：脚本会自动检查电脑环境。为了避免命令行管道读取不到键盘输入，交付命令默认使用自动确认模式。如果想手动确认每一步，可以先下载脚本再运行：curl -fsSL "..." -o install-claude-code.sh && bash install-claude-code.sh
⚠️ 注意：请完整复制整行命令，不要手动输入（容易打错字母）。不要漏掉开头的 iwr（Windows）或 curl（Mac）。

第三步：粘贴命令，按回车

1

把刚才复制的命令粘贴到终端窗口

Windows PowerShell：直接右键点击窗口即可粘贴（或按 Ctrl+V）。
Mac 终端：按 Command+V 粘贴。

2

按键盘上的 Enter / Return 回车键

命令开始运行。你会看到一些文字输出，这是正常的。

💡 如果粘贴不了：试试右键 → 粘贴，或者 Shift+Insert（Windows）。如果还是不行，检查确认复制时真的选中了整行命令。

第四步：跟着提示操作

安装脚本会自动检查你的电脑环境并安装 Claude Code：

  1. 脚本会显示 "正在检查你的电脑环境…"
  2. 检查系统、网络、是否已安装过 Claude Code
  3. 确认提示会自动跳过（AGENT_INSTALL_YES=1 模式），脚本直接进入安装
  4. 脚本通过官方渠道自动安装 Claude Code
  5. 看到 "✅ Claude Code 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。把错误截图保存下来，然后访问故障排查页面：
https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.8/docs/support.html

第五步：配置 DeepSeek API

安装完成后，脚本会自动询问你是否配置 DeepSeek API。

1

看到 "是否现在配置 DeepSeek API？" 时，输入 y 回车

2

粘贴你的 DeepSeek API Key（以 sk- 开头），回车

输入时不会显示字符，这是正常的安全保护，粘贴后直接回车即可。

3

看到 "✅ DeepSeek API 配置完成"

配置会自动写入系统，永久生效。

💡 如果没有 DeepSeek API Key：可以跳过此步骤（输入 n 或直接回车）。如果你已有 Claude 官方账号，也可以稍后运行 claude login 用官方方式登录。

怎么知道安装成功了？

  • 在终端输入 claude --version，能看到版本号（如 v1.0.x）
  • 输入 claude 能进入对话界面，直接和 AI 对话
  • 如果已配置 DeepSeek API，Claude Code 将使用 DeepSeek 作为后端模型

常见问题

Q: 关闭终端重开后，输入 claude 提示"找不到命令"？

A: 重新运行一遍安装脚本即可，它会自动识别已有安装并修复 PATH。

Q: 需要安装 Node.js 吗？

A: 不需要。Claude Code 自带运行时，不需要单独安装 Node.js。

Q: 在哪里获取 DeepSeek API Key？

A: 浏览器打开 platform.deepseek.com，手机号注册后，在左侧菜单"API Keys"中创建。Key 以 sk- 开头。充值 ¥1 起，按量扣费。

Q: Claude Code 启动后提示需要登录？

A: 说明 DeepSeek API 配置未生效。关掉终端重新打开（环境变量需要新窗口才能加载），再试 claude。或者运行 claude login 使用 Claude 官方账号登录。

Q: 我已经有 Claude 官方账号，怎么用？

A: 安装脚本的 DeepSeek 配置步骤可以跳过。安装后直接在终端输入 claude login，浏览器会弹出 Claude 登录页。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.8/docs/support.html

安装好了，接下来做什么？

  1. 在终端输入 claude 启动对话
  2. 试试问它："帮我写一个 Hello World 程序"
  3. 用 claude "解释这段代码" 让 Claude 分析你当前目录的代码
  4. 探索更多功能：claude --help 查看所有可用命令
