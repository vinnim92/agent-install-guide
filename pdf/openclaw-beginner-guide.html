小白安装手册

微软开源 · 命令行 AI 编程助手 · 推荐 DeepSeek API Key

版本 v3.0.7|支持 Windows / Mac

适用对象

本手册适合第一次接触命令行的新手用户。如果你平时只用鼠标操作电脑，从没打开过"终端"或"PowerShell"，本手册会手把手带你完成安装。

✅ 安装阶段不需要 API Key。首次配置或正式使用时，推荐使用 DeepSeek API Key（国内获取方便、价格便宜）。安装脚本会自动检测并安装 Node.js（需要 v22.19+，推荐 v24+），你不需要手动安装任何依赖。

安装前准备

🔑 推荐准备 DeepSeek API Key

安装阶段不需要 API Key。首次配置或正式使用时，推荐使用 DeepSeek API Key（在 platform.deepseek.com 注册获取，以 sk- 开头）。也可以使用 OpenAI / Claude 等第三方 API Key。

💻 电脑系统要求

Windows 10/11 或 macOS 10.15+（也支持 Linux）

🌐 需要网络连接

安装过程需要联网下载 Node.js 和 OpenClaw。免费模型需要网络连接才能使用。

第一步：打开终端 / PowerShell

🪟 Windows 用户

1

点击"开始"菜单（屏幕左下角 Windows 图标）

2

在搜索框输入 PowerShell

搜索结果会出现蓝色图标的"Windows PowerShell"。

3

点击打开

弹出一个白底黑字（或蓝底白字）的窗口，能看到闪烁的光标，这就是命令行界面。

💡 提示：你也可以右键点击"开始"菜单 → 选择"Windows 终端"或"PowerShell"。

🍎 Mac 用户

1

点击程序坞（Dock）上的 Launchpad 图标（火箭）

2

在搜索框输入 终端

或者在 Finder 中打开：应用程序 → 实用工具 → 终端.app

3

双击打开"终端"

弹出一个白底黑字的窗口，能看到闪烁的光标和你的用户名。这就是命令行界面。

💡 提示：按 Command + 空格 打开 Spotlight，输入"终端"然后回车，这是最快的方式。

第二步：复制安装命令

⚠️ 重要提醒：PDF 里的长命令有时会因换行，复制后被拆成两段。
如果你看到命令里出现类似 @v3.0. 和下一行 7/scripts/...，说明命令被拆坏了。
请优先打开交付包里的《06-一键复制命令.txt》，从里面复制完整命令。
正确命令必须是一整行
❌ 错误（被拆断）：
@v3.0.
7/scripts/...
✅ 正确（完整）：
@v3.0.7/scripts/...

选中下面 对应你电脑系统 的那行命令，完整复制（用鼠标选中 → 右键复制，或按 Ctrl+C / Command+C）：

为避免复制断行，请优先从《06-一键复制命令.txt》中复制。

🪟 Windows 用户（在 PowerShell 中运行）

Windows PowerShell iwr -useb "https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.7/scripts/install-openclaw.ps1" | iex

🍎 Mac 用户（在终端中运行）

macOS 终端 curl -fsSL "https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.7/scripts/install-openclaw.sh" | AGENT_INSTALL_YES=1 bash
💡 Mac 命令中的 AGENT_INSTALL_YES=1：脚本会自动检查电脑环境。为了避免命令行管道读取不到键盘输入，交付命令默认使用自动确认模式。如果想手动确认每一步，可以先下载脚本再运行：curl -fsSL "..." -o install-openclaw.sh && bash install-openclaw.sh
⚠️ 注意：请完整复制整行命令，不要手动输入（容易打错字母）。不要漏掉开头的 iwr（Windows）或 curl（Mac）。

第三步：粘贴命令，按回车

1

把刚才复制的命令粘贴到终端窗口

Windows PowerShell：直接右键点击窗口即可粘贴（或按 Ctrl+V）。
Mac 终端：按 Command+V 粘贴。

2

按键盘上的 Enter / Return 回车键

命令开始运行。你会看到一些文字输出，这是正常的。

💡 如果粘贴不了：试试右键 → 粘贴，或者 Shift+Insert（Windows）。如果还是不行，检查确认复制时真的选中了整行命令。

第四步：跟着提示操作

安装脚本会自动检查你的电脑环境，如果需要还会自动安装 Node.js：

  1. 脚本会显示 "正在检查你的电脑环境…"
  2. 检查系统、网络、Node.js 版本、是否已安装过 OpenClaw
  3. 如果 Node.js 版本不够（需要 >= 22.19），脚本会询问是否自动安装 → 输入 y 回车
  4. 确认提示会自动跳过（AGENT_INSTALL_YES=1 模式），脚本直接进入安装
  5. 脚本通过官方渠道自动安装 OpenClaw
  6. 看到 "✅ OpenClaw 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。把错误截图保存下来，然后访问故障排查页面：
https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.7/docs/support.html

第五步：首次配置（推荐 DeepSeek API Key）

安装完成后，关掉当前的终端/PowerShell 窗口，重新打开一个新窗口，然后：

在终端 / PowerShell 中运行（按提示输入 DeepSeek API Key） openclaw onboard --auth-choice deepseek-api-key

验证配置是否成功：

查看可用模型 openclaw models list --provider deepseek

启动 Web 控制台（图形化界面，对新手更友好）：

在终端 / PowerShell 中输入（Web 控制台） openclaw dashboard
💡 DeepSeek API Key 获取方式：打开浏览器访问 platform.deepseek.com，注册 → API Keys → 创建 Key（以 sk- 开头）。

怎么知道安装成功了？

  • 在终端输入 openclaw --version，能看到版本号
  • 输入 openclaw 能进入对话界面
  • 输入 openclaw dashboard 能看到 Web 控制台地址
  • 输入 openclaw models list --provider deepseek 能列出可用模型

常见问题

Q: 关闭终端重开后，输入 openclaw 提示"找不到命令"？

A: 重新运行一遍安装脚本即可，它会自动识别已有安装并修复 PATH。

Q: 安装脚本提示 Node.js 安装失败？

A: 手动去 https://nodejs.org 下载并安装 LTS 版本（左侧绿色按钮），装完后再运行一次 OpenClaw 安装脚本。OpenClaw 需要 Node.js >= 22.19，推荐 v24+。

Q: 需要 API Key 吗？

A: 安装阶段不需要 API Key。首次配置或正式使用时，推荐使用 DeepSeek API Key，在 platform.deepseek.com 注册获取（以 sk- 开头）。

Q: npm install 报 EACCES / permission denied？

A: 这是 npm 缓存权限异常，通常是以前用 sudo npm 或安装器异常导致 ~/.npm 目录中部分文件不属于当前用户。修复方法：

sudo chown -R "$(id -u):$(id -g)" "$HOME/.npm"
chmod -R u+rwX "$HOME/.npm"
npm cache verify

然后重新运行安装命令。详见故障排查页面。

Q: OpenAI Codex OAuth 报 unsupported_region？

A: 这是 OpenAI Codex OAuth 在当前国家、地区或网络路线下无法完成认证，不是 OpenClaw 安装失败。大陆用户建议改用 DeepSeek API Key：openclaw onboard --auth-choice deepseek-api-key

Q: 怎么打开 Web 控制台？

A: 在终端输入 openclaw dashboard，然后浏览器访问终端显示的地址（通常是 http://localhost:18789）。

Q: Mac 上提示缺少编译依赖？

A: 在终端运行 xcode-select --install，弹出窗口点"安装"，等安装完成后再运行 OpenClaw 安装脚本。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.7/docs/support.html

安装好了，接下来做什么？

  1. 运行 openclaw onboard --auth-choice deepseek-api-key 配置 DeepSeek API Key
  2. 运行 openclaw models list --provider deepseek 验证配置
  3. 运行 openclaw dashboard 打开 Web 控制台
  4. 在终端输入 openclaw 启动对话，试试问它："帮我写一个计算器程序"
  5. 探索更多功能：openclaw --help 查看所有可用命令
