小白安装手册

微软开源 · 命令行 AI 编程助手 · 推荐 DeepSeek API Key

版本 v3.1.1|支持 Windows / Mac

适用对象

本手册适合第一次接触命令行的新手用户。如果你平时只用鼠标操作电脑，从没打开过"终端"或"PowerShell"，本手册会手把手带你完成安装。

✅ 安装阶段不需要 API Key。首次配置或正式使用时，推荐使用 DeepSeek API Key（国内获取方便、价格便宜）。安装脚本会自动检测并安装 Node.js（需要 v22.19+，推荐 v24+），你不需要手动安装任何依赖。

安装前准备

🔑 推荐准备 DeepSeek API Key

安装阶段不需要 API Key。首次配置或正式使用时，推荐使用 DeepSeek API Key（在 platform.deepseek.com 注册获取，以 sk- 开头）。也可以使用 OpenAI / Claude 等第三方 API Key。

💻 电脑系统要求

Windows 10/11 或 macOS 10.15+（也支持 Linux）

🌐 需要网络连接

安装过程需要联网下载 Node.js 和 OpenClaw。模型访问需要网络连接。

第一步：打开终端 / PowerShell

🪟 Windows 用户

1

点击"开始"菜单（屏幕左下角 Windows 图标）

2

在搜索框输入 PowerShell

搜索结果会出现蓝色图标的"Windows PowerShell"。

3

点击打开

弹出一个白底黑字（或蓝底白字）的窗口，能看到闪烁的光标，这就是命令行界面。

💡 提示：你也可以右键点击"开始"菜单 → 选择"Windows 终端"或"PowerShell"。

🍎 Mac 用户

1

点击程序坞（Dock）上的 Launchpad 图标（火箭）

2

在搜索框输入 终端

或者在 Finder 中打开：应用程序 → 实用工具 → 终端.app

3

双击打开"终端"

弹出一个白底黑字的窗口，能看到闪烁的光标和你的用户名。这就是命令行界面。

💡 提示：按 Command + 空格 打开 Spotlight，输入"终端"然后回车，这是最快的方式。

第二步：复制安装命令

⚠️ 重要：请复制整行命令。如果粘贴后变成两行，请删除换行，让它保持一整行。

选中下面 对应你电脑系统 的那行命令，完整复制（用鼠标选中 → 右键复制，或按 Ctrl+C / Command+C）：

为避免复制断行，请优先从《06-一键复制命令.txt》中复制。

🪟 Windows 用户（在 PowerShell 中运行）

Windows PowerShell irm https://vinnim92.github.io/agent-install-guide/i/openclaw.ps1 | iex

🍎 Mac 用户（在终端中运行）

macOS 终端 curl -fsSL https://vinnim92.github.io/agent-install-guide/i/openclaw.sh | bash
📌 关于这条短命令：这条短命令会自动获取最新稳定版安装脚本，普通用户不需要关心版本号。如果 CDN 暂时访问失败，脚本会自动尝试备用下载地址。
💡 Mac 命令中的 AGENT_INSTALL_YES=1：脚本会自动检查电脑环境。为了避免命令行管道读取不到键盘输入，交付命令默认使用自动确认模式。如果想手动确认每一步，可以先下载脚本再运行：curl -fsSL "..." -o openclaw.sh && bash openclaw.sh

第三步：粘贴命令，按回车

1

把刚才复制的命令粘贴到终端窗口

Windows PowerShell：直接右键点击窗口即可粘贴（或按 Ctrl+V）。
Mac 终端：按 Command+V 粘贴。

2

按键盘上的 Enter / Return 回车键

命令开始运行。你会看到一些文字输出，这是正常的。

💡 如果粘贴不了：试试右键 → 粘贴，或者 Shift+Insert（Windows）。如果还是不行，检查确认复制时真的选中了整行命令。

第四步：跟着提示操作

安装脚本会自动检查你的电脑环境并安装 OpenClaw：

  1. 脚本会显示 "正在检查你的电脑环境…"
  2. 自动检查 Node.js 版本（需要 ≥ v22.19），如不满足会自动安装或升级
  3. 确认提示会自动跳过（AGENT_INSTALL_YES=1 模式），脚本直接进入安装
  4. 脚本通过官方渠道自动安装 OpenClaw
  5. 看到 "✅ OpenClaw 安装成功" 就完成了
💡 如果中途出现红色报错：不要慌。把错误截图保存下来，然后访问故障排查页面：
https://vinnim92.github.io/agent-install-guide/docs/support.html

怎么知道安装成功了？

  • 在终端输入 openclaw --version，能看到版本号
  • 输入 openclaw 能进入对话界面
  • 启动命令是 openclaw

首次使用：配置模型

安装完成后，首次运行 openclaw 时需要选择一个模型提供商。推荐 DeepSeek：

  1. 输入 openclaw onboard 进入配置引导
  2. 选择 DeepSeek 作为模型提供商
  3. 粘贴你的 DeepSeek API Key（以 sk- 开头）
  4. 也可选择其他提供商（OpenAI / Anthropic / 等 75+ 种）
💡 OpenClaw 支持 75+ 种模型提供商。你可以随时通过 openclaw onboard 重新配置。

常见问题

Q: 关闭终端重开后，输入 openclaw 提示"找不到命令"？

A: 重新运行一遍安装脚本即可，它会自动识别已有安装并修复 PATH。

Q: 需要什么版本的 Node.js？

A: 需要 Node.js ≥ v22.19（推荐 v24+）。安装脚本会自动检查和安装。

Q: 没有 DeepSeek API Key 可以用吗？

A: 需要配置 API Key 才能使用模型。推荐 DeepSeek（国内方便、便宜），也支持 OpenAI、Anthropic 等 75+ 种提供商。

Q: npm 安装失败怎么办？

A: 脚本会自动重试并切换国内镜像（npmmirror.com）。如果反复失败，访问故障排查页面检查 npm 缓存权限问题。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://vinnim92.github.io/agent-install-guide/docs/support.html

安装好了，接下来做什么？

  1. 在终端输入 openclaw 启动对话
  2. 试试问它："帮我审查这段代码的安全性"
  3. 用 openclaw "重构这个函数" 让 OpenClaw 改进你的代码
  4. 探索更多功能：openclaw --help 查看所有可用命令

安全说明

  • 脚本只安装 OpenClaw，不会多装其他东西
  • 脚本支持 --dry-run 预演，安装前可以先看清楚每一步
  • 涉及环境修改时会提示你确认
  • 所有脚本在 GitHub 开源，代码随时可查看
