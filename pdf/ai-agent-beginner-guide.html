这是什么？

这是一个帮你一键安装 AI 编程助手的工具包。你不需要：

  • 研究英文文档
  • 手动配置 Node、npm、PATH
  • 在各种教程之间来回跳转

你只需要选择自己的系统和想安装的 Agent，复制对应命令，跟着提示完成安装。

三个 Agent，怎么选？

🔶 Claude Code + DeepSeek API

适合：追求综合能力最强的用户。
出品方：Anthropic。
推荐方案：DeepSeek API Key（国内获取方便、价格便宜）。也支持 Claude 官方账号登录。
特点：自带运行时，不需要安装 Node.js。装好就能用。
启动命令：claude

🟢 Codex

适合：ChatGPT 用户或 OpenAI API 用户。
出品方：OpenAI。
推荐方案：ChatGPT 官方账号登录，或 OpenAI API Key 登录。
特点：与 ChatGPT 生态深度打通，需要安装 Node.js（脚本自动处理）。
启动命令：codex

🟣 OpenClaw + DeepSeek

适合：想尝试开源 Agent 工作流的用户。
出品方：微软（开源）。
推荐方案：DeepSeek API Key（国内方便、便宜）。
特点：支持 75+ 模型提供商，需要安装 Node.js ≥ v22.19（脚本自动处理）。
启动命令：openclaw

Windows 安装

按 ⊞ + R，输入 powershell，回车。粘贴你选的 Agent 对应的命令。

⚠️ 重要：请复制整行命令。如果粘贴后变成两行，请删除换行，让它保持一整行。

Claude Code

irm https://vinnim92.github.io/agent-install-guide/i/claude.ps1 | iex

Codex

irm https://vinnim92.github.io/agent-install-guide/i/codex.ps1 | iex

OpenClaw

irm https://vinnim92.github.io/agent-install-guide/i/openclaw.ps1 | iex
📌 关于短命令：这些短命令会自动获取最新稳定版安装脚本，普通用户不需要关心版本号。如果 CDN 暂时访问失败，脚本会自动尝试备用下载地址。

为避免复制断行，请优先从《06-一键复制命令.txt》中复制。

⚠️ 重要：请复制整行命令。如果粘贴后变成两行，请删除换行，让它保持一整行。

常见问题

Q: 我需要先安装什么吗？

A: 不需要。复制命令即可，不需要任何准备工作。脚本会自动检测和安装所需环境。

Q: 可以同时安装多个 Agent 吗？

A: 可以，但建议分开安装。每个 Agent 设计为独立安装，逐个来更清楚、更稳定。

Q: 安装后怎么启动？

A: 在终端输入 claude、codex 或 openclaw 即可。安装完成的最后一行也会提示你。

Q: 国内网络能用吗？

A: 安装脚本通过 CDN 分发，对国内用户友好。如果 CDN 暂时失败，会自动切换备用地址。具体 Agent 的登录和模型访问取决于对应服务本身的网络情况。

Q: 可以重复运行吗？

A: 可以。脚本会检测已安装的内容，不会重复安装。也可以用来更新到最新版。

Q: 安装失败了怎么办？

A: 打开故障排查页面，按步骤检查：
https://vinnim92.github.io/agent-install-guide/docs/support.html

安全说明

  • 每个脚本只安装一个 Agent，不会多装其他东西
  • 脚本支持 --dry-run 预演，安装前可以先看清楚每一步
  • 涉及环境修改时会提示你确认
  • 所有脚本在 GitHub 开源，代码随时可查看
