03 · 安装前的 3 个概念

1. 终端是什么？

终端就是你电脑里的一个黑底白字的窗口，它是你和电脑"直接说话"的地方。
平常你点鼠标操作，终端里你是用键盘输入命令操作。
这次安装，你需要打开终端，把命令粘贴进去，按回车就行。

系统怎么打开终端
Mac点右上角 🔍 搜索「终端」，打开
Linux打开系统自带的「终端」
Windows按 ⊞ + R，输入 powershell，回车

2. dry-run 是什么？

dry-run = 预演模式。
加了 --dry-run 参数后，脚本只会告诉你"如果正式安装，我会做什么"，并不会真的修改你电脑的任何东西。
对小白特别友好——先看清楚流程，再决定是否正式安装。

3. API Key / 账号 / 订阅是什么？

AI Agent 本质上是把 AI 能力接入你的电脑。
Claude Code 需要 Claude 的账号（去 claude.ai 注册）。
Codex 需要 OpenAI 的账号（去 chatgpt.com 注册）。
OpenClaw 内置免费模型，不配置也能先跑起来。
安装脚本只负责把工具装好，不包含账号注册。

04 · 推荐流程：先预演，再安装

正式安装前，建议先用 dry-run 预演一遍。它不会安装任何东西，只是告诉你脚本准备做什么。

macOS / Linux：预演

以 Codex 为例：

curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-codex.sh | bash -s -- --dry-run

把 install-codex 换成 install-claude-code 或 install-openclaw 即可预演其他 Agent。

Windows：预演

以 Codex 为例（两步）：

iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-codex.ps1 -OutFile install-codex.ps1
.\install-codex.ps1 -DryRun

把 install-codex 换成 install-claude-code 或 install-openclaw 即可。

dry-run 输出长什么样？
你会看到以 [DRY-RUN] 将执行: 开头的一行行文字，告诉你脚本会检查什么、安装什么。最后会显示"预览完成 — 以上步骤未实际执行"。

05 · macOS / Linux 安装命令

打开终端，复制你选的 Agent 对应的命令，回车。

Claude Code

curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-claude-code.sh | bash

Codex

curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-codex.sh | bash

OpenClaw

curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-openclaw.sh | bash
想跳过确认？在命令最前面加 AGENT_INSTALL_YES=1 （注意空格），例如：
AGENT_INSTALL_YES=1 curl -fsSL https://... | bash

06 · Windows PowerShell 安装命令

按 ⊞ + R，输入 powershell，回车。粘贴你选的 Agent 对应的命令。

Claude Code

iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-claude-code.ps1 | iex

Codex

iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-codex.ps1 | iex

OpenClaw

iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.5/scripts/install-openclaw.ps1 | iex
想跳过确认？在粘贴安装命令之前，先输入：
$env:AGENT_INSTALL_YES = "1" 并回车，然后再粘贴安装命令。

07 · 正式安装流程

整个安装只需要三步：

1 复制对应命令
从第 05 节（macOS/Linux）或第 06 节（Windows）中找到你要装的 Agent，选中整行命令，复制。

2 看到中文提示后确认
粘贴命令到终端，回车。脚本会自动检测你的系统、检查环境、询问你是否继续。
看到 [?] 提示时，直接回车就是确认。

3 等待安装完成
脚本会自动完成剩余步骤。你不需要做任何其他操作。
最后看到 ✅ 安装验证通过 就完成了。

安装过程中可能会问你是否安装 Node.js
Codex 和 OpenClaw 需要 Node.js。如果脚本提示需要安装，按回车确认即可，脚本会自动处理。
Claude Code 自带运行时，不需要额外安装 Node.js。

08 · 安装完成后怎么启动

安装完成后，在终端或 PowerShell 中输入对应命令启动：

安装了哪个启动命令会发生什么
Claude Code claude 浏览器弹出 Claude 登录页，登录后回到终端开始对话
Codex codex 浏览器弹出 ChatGPT 登录页，登录后回到终端开始对话
OpenClaw openclaw 直接在终端进入交互式对话（或 openclaw dashboard 打开 Web 控制台）
找不到命令？
关掉终端窗口重新打开再试。这是因为终端需要刷新一下"环境路径"。

09 · 安装成功的判断标准

装好了是以下三种情况中的任意一种：

  1. 终端显示 ✅ 安装验证通过 或类似成功提示
  2. 输入启动命令有响应：输入 claude、codex 或 openclaw 后，终端不是显示"找不到命令"
  3. 进入了登录或对话界面：浏览器弹出登录页，或终端直接进入交互模式

这三条中满足任意一条，就说明安装成功了。

如果没有——回到第 04 节，先用 dry-run 预演一遍，看看是哪一步出了问题。也可以跳到第 11 节用反馈模板求助。

10 · 常见问题 FAQ

Q1：我需要下载 GitHub 仓库吗？

不需要。你只需要复制这一条命令，脚本会从云端自动加载。

Q2：我需要懂编程吗？

不需要。照着命令复制粘贴，看到提示按确认就可以。

Q3：为什么每次只装一个 Agent？

更清楚、更稳定。出问题也更容易定位是哪一个。想装多个 Agent 就重复操作，互不影响。

Q4：我可以重复运行脚本吗？

可以。脚本会检查是否已经安装过了，不会重复安装。想升级到最新版，重新运行一次就行。

Q5：安装后还需要账号吗？

需要。安装脚本只负责把 Claude Code、Codex 或 OpenClaw 装进你的电脑。实际使用时：Claude Code 需要 Claude 账号；Codex 需要 OpenAI/ChatGPT 账号；OpenClaw 内置免费模型，可以先跑起来。

Q6：国内网络能不能用？

安装脚本通过 jsDelivr CDN 分发，对国内用户更友好。具体 Agent 的登录和模型访问取决于对应服务本身的网络情况。

Q7：失败了怎么办？

先运行 dry-run 预演（见第 04 节），把报错截图。然后用第 11 节的反馈模板求助。

Q8：我该先装哪一个？

没有对错之分。想获得最稳定的体验 → Claude Code。你是 ChatGPT 深度用户 → Codex。想玩开源、尝试不同模型 → OpenClaw。
