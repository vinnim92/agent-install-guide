# 闲鱼封面文案模板

---

## 封面一

**主标题：** AI Agent 小白安装包

**副标题：** 复制一条命令，5 分钟装好 Claude Code / Codex / OpenClaw

**卖点：**
- 不用看英文文档
- 自动检测环境 · 自动安装依赖
- 中文提示 · 出错了告诉你怎么办

**视觉风格：** 深色终端风格。中央一个代码块，绿色光标闪烁。上方白色大字标题。适合科技感、技术工具类商品。

---

## 封面二

**主标题：** 不会配环境？

**副标题：** 选系统 → 选 Agent → 复制命令 → 装好启动。就这样。

**卖点：**
- 不用懂 Node / npm / PATH
- 脚本自包含，一条命令搞定
- 支持 dry-run 预演，先看再装

**视觉风格：** 白色简洁电商风。左侧大标题，右侧三步流程图（系统→Agent→命令→✅）。配柔和渐变色块。适合吸引小白用户。

---

## 封面三

**主标题：** 把 Claude Code 装进你的电脑

**副标题：** 一条命令，自动安装。会复制粘贴就能搞定。

**卖点：**
- Anthropic 出品，最强 AI 编程助手之一
- 无需手动安装 Node.js
- macOS / Windows 都支持

**视觉风格：** Claude Code 品牌色系（米色/棕色），右侧展示终端窗口截图。适合针对特定 Agent 的单品封面。

---

## 封面四

**主标题：** 想用 AI Agent？先过安装这一关

**副标题：** 医生/学生/自媒体也能装。一条命令，跟着中文提示。

**卖点：**
- 不是十几篇教程拼起来的
- 每个 Agent 独立脚本，互不干扰
- GitHub 开源 · jsDelivr CDN 国内友好

**视觉风格：** 痛点导向。上半部分灰色调列出"不会Node""看不懂英文报错""装了好几次都失败"，下半部分亮色展示解决方案。对比强烈。

---

## 封面五

**主标题：** 你的电脑还没装 AI 编程助手？

**副标题：** Claude Code / Codex / OpenClaw 三选一，一条命令，5 分钟启动。

**卖点：**
- 自动检测环境 · 自动修复问题
- 安装前可 dry-run 预演
- 装不上截图找我，24 小时在线

**视觉风格：** 生活化风格。左侧摆放三个 Agent 图标（Claude Code / Codex / OpenClaw），右侧大标题。底部一行"复制命令 → 跟着提示 → 装好"。暖色调，亲和力强。

---

## 尺寸要求（闲鱼）

- 主图：800 × 800 px（1:1）
- 详情图：宽 750 px，高不限
- 建议主图用大字标题 + 简约设计，第一眼能看清卖的是什么

## 配色建议

- **科技感路线**：深蓝/深灰底色 + 绿色/青色终端文字
- **亲和小白路线**：白色/浅灰底色 + 暖色点缀（橙色/黄色）
- **专业可信路线**：深色底色 + 金色/白色文字，强调 GitHub 开源
