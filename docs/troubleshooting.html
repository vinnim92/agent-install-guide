AI Agent 安装故障排查

遇到问题了？按下面的错误类型找到对应解决方法

命令没有反应 / 卡住了

  • 等待 2–3 分钟：首次安装需要下载文件，请耐心等待，不要关闭窗口。
  • 检查网络：公司或学校 Wi-Fi 可能屏蔽了 GitHub / npm 等网站。尝试切换手机热点再试。
  • 关闭代理 / VPN：如果你开了 VPN 或代理，先关闭后再试一次。
  • 按 Ctrl+C 取消后重试：偶尔网络波动会导致下载中断，重新运行安装命令即可。
  • 换个网络环境：比如从公司网络切换到家庭 Wi-Fi 或手机热点。

下载失败（curl / irm 报错）

  • macOS / Linux：确认命令以 curl -fsSL 开头，不要漏掉 -fsSL 参数。
  • Windows PowerShell：确认命令以 irm 开头（不是 iwr）。
  • 确保命令完整复制：从 PDF 或网页上完整复制整行命令，不要手动输入。
  • 关闭防火墙 / 安全软件：部分安全软件会拦截来自 Internet 的脚本。暂时关闭后再试。
  • 如果反复失败：可能是 CDN 被运营商限制。尝试切换手机热点。

国内网络访问 GitHub / jsDelivr 不稳定

  • 现象：安装命令报错"基础连接已经关闭""发送时发生错误"或"Failed to fetch from GitHub"。
  • 原因：GitHub Pages 和 jsDelivr CDN 在中国大陆可能被限制或速度极慢。jsDelivr 依赖 GitHub 回源，在国内也不是独立可用的 CDN。
  • 推荐方案 — 使用 Gitee 国内镜像：
    # Windows PowerShell $env:GITEE_ACCOUNT="<你的Gitee账号>" irm https://vinnim92.github.io/agent-install-guide/i/codex.ps1 | iex # macOS / Linux export GITEE_ACCOUNT="<你的Gitee账号>" curl -fsSL https://vinnim92.github.io/agent-install-guide/i/codex.sh | bash
    设置 GITEE_ACCOUNT 环境变量后，脚本会优先从 Gitee 国内镜像下载安装脚本，速度更快、更稳定。
  • 如果 irm 仍然失败：可改用 curl.exe 下载后执行：
    $u="https://gitee.com/<账号>/agent-install-guide/raw/main/docs/i/codex.ps1" $p="$env:TEMP\codex.ps1" curl.exe -L $u -o $p powershell -ExecutionPolicy Bypass -File $p
  • 搭建 Gitee 镜像：参见仓库中的 GITEE_MIRROR.md 文档。

权限错误（Permission denied / EACCES）

  • macOS / Linux：安装过程中如果遇到 Permission denied，按照提示选择 "Y" 即可。
  • macOS 额外步骤：某些 Mac 可能需要先允许终端访问"开发工具"。系统提示时点"允许"即可。
  • Windows：右键点击 PowerShell 图标 → 选择"以管理员身份运行"，然后重新执行安装命令。
  • 不要用 sudo：在 Mac/Linux 上，不要用 sudo npm install -g。

找不到命令（command not found / 无法识别）

  • 第一步：关闭终端 / PowerShell 窗口，重新打开。这是最常见的问题——安装成功但 PATH 未立即生效。
  • macOS / Linux：
    # 检查是否已安装（在终端粘贴运行） which claude # Claude Code which codex # Codex which openclaw # OpenClaw
    如果有输出路径但运行报错，说明 PATH 问题。关掉终端重新打开。
  • Windows：
    # 在 PowerShell 中检查 Get-Command claude # Claude Code Get-Command codex # Codex Get-Command openclaw # OpenClaw
  • 重新运行安装脚本：如果关闭重开终端后依然找不到命令，重新运行安装脚本即可。

Node.js 版本问题

  • Claude Code：自带运行时，不需要 Node.js。
  • Codex：需要 Node.js ≥ v22。安装脚本会自动检查和安装。
  • OpenClaw：需要 Node.js ≥ v22.19（推荐 v24+）。同样由脚本自动安装。
  • 检查当前版本：
    node -v
    如果版本号小于 v22.0.0，则需要升级 Node.js。
  • 手动安装 Node.js：访问 https://nodejs.org，下载左侧推荐的 LTS 版本安装。

Windows — npm.ps1 cannot be loaded

  • 现象：安装过程中出现红色报错，包含 npm.ps1 cannot be loaded 或 因为在此系统上禁止运行脚本。
  • 原因：Windows PowerShell 默认执行策略可能禁止运行 .ps1 脚本。
  • 推荐解决方案：升级到 v3.1.1 或更新版本。新版脚本优先调用 npm.cmd，从根本上避免此问题。
    irm https://vinnim92.github.io/agent-install-guide/i/codex.ps1 | iex
  • 临时解决方案：
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
    然后重新运行安装命令。此设置仅当前窗口有效，关闭后自动失效。

Windows PowerShell 显示问号（???）

  • 现象：安装过程中输出的中文文字变成了一串 ?????????????。
  • 原因：Windows PowerShell 5.1 控制台编码与脚本编码不一致。
  • 推荐解决方案：升级到 v3.1.1 或更新版本。新版脚本保存为 UTF-8 with BOM，并自动设置控制台为 UTF-8。
    irm https://vinnim92.github.io/agent-install-guide/i/codex.ps1 | iex
  • 临时解决方案：
    chcp 65001
    然后在同一个 PowerShell 窗口重新运行安装命令。
  • 说明：问号乱码不影响安装逻辑的正确性。即使看到 ???，安装操作本身仍在正常执行。

Claude Code — DeepSeek API 配置问题

  • Claude Code 已安装，但 DeepSeek API 配置失败：关掉终端重新打开（环境变量需新窗口才能加载），再试 claude。
  • DeepSeek API Key 粘贴后没反应：输入 Key 时光标不会移动是正常的（安全输入模式），粘贴后直接回车即可。
  • Claude Code 启动后仍提示 Anthropic / Claude 登录：说明环境变量未生效。确认 ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic 已设置。Mac/Linux 用户运行 source ~/.zshrc 然后重试。
  • 如何手动重新配置：重新运行安装脚本，或手动设置 ANTHROPIC_BASE_URL 和 ANTHROPIC_AUTH_TOKEN 环境变量。

Codex — 登录 / API Key 问题

  • Codex 官方网页登录失败：确认 ChatGPT 账号有 Plus/Pro/Team 订阅。免费版不支持 Codex。
  • API Key 登录失败：确认 OPENAI_API_KEY 环境变量已正确设置。Key 以 sk- 开头。
  • API Key 已设置但 Codex 不识别：关掉终端重新打开（环境变量需新窗口加载）。
  • API Key 提示余额不足：登录 platform.openai.com 检查用量和余额。

OpenClaw — EACCES / permission denied

  • 现象：npm error EACCES: permission denied，路径里出现 ~/.npm/_cacache。
  • 原因：npm 缓存目录权限异常，通常是以前用 sudo npm 导致文件不属于当前用户。
  • macOS / Linux 修复：
    sudo chown -R "$(id -u):$(id -g)" "$HOME/.npm" chmod -R u+rwX "$HOME/.npm" npm cache verify npm install -g openclaw@latest --registry=https://registry.npmjs.org/ --no-audit --no-fund
  • Windows：以管理员身份运行 PowerShell：
    npm cache clean --force npm install -g openclaw@latest --registry=https://registry.npmjs.org/ --no-audit --no-fund

OpenClaw — DeepSeek 配置问题

  • 安装阶段不需要 API Key。首次使用时推荐 DeepSeek API Key。
  • 配置命令：
    openclaw onboard --auth-choice deepseek-api-key
    按终端提示输入你的 DeepSeek API Key（在 platform.deepseek.com 注册获取）。
  • 验证：
    openclaw models list --provider deepseek

如何截图反馈

  • Windows：按 ⊞ + Shift + S 截图，或按 Print Screen 键。
  • Mac：按 Command + Shift + 4 截取屏幕区域，截图保存在桌面。

通用排查思路：
1. 关掉终端 → 重新打开 → 重试
2. 切换网络（手机热点）→ 重试
3. 重启电脑 → 重试
4. 大部分安装问题都可以通过以上三步解决。
