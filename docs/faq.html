常见问题排查

Claude Code 安装与使用 · 10 个最常见问题 · 每个都有手把手解决方案

🔧 遇到问题第一步：在终端运行 claude doctor 自诊断

1. 输入 claude 提示「command not found」

原因：安装目录不在系统 PATH 中，新终端未刷新环境变量。
Mac / Linux：关掉终端，重新打开，再试。如果还不行： 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
Windows：重启电脑一次。或将 %USERPROFILE%\.local\bin 添加到系统环境变量 PATH 中。

2. 安装时提示 EACCES 权限错误

原因：用了 sudo 安装，或 npm 全局目录权限不对。
不要用 sudo。改为用我们的安装脚本（已自动处理权限）： 
curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@main/scripts/install-claude-code.sh | bash

3. Node 版本太旧 / 启动后静默崩溃

原因：Claude Code 需要 Node 18 或更高版本。
检查当前版本：node -v
如果低于 v18，安装最新版： 
# Mac
brew install node@22

# 或访问 https://nodejs.org 下载安装包（和装微信一样简单）
我们的安装脚本已自动处理 Node.js 安装，优先使用脚本安装。

4. Windows PowerShell 安装失败 / 没有反应

原因：PowerShell 执行策略限制，或 Windows 版安装器有已知兼容问题。
方法一：先解除策略限制，再运行安装命令： 
Set-ExecutionPolicy Bypass -Scope Process -Force
iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@main/scripts/install-claude-code.ps1 | iex
方法二：如果 PowerShell 持续失败，用 CMD（命令提示符）代替。按 ⊞+R，输入 cmd，回车。

5. 公司 / 学校网络下安装卡住

原因：企业防火墙或代理拦截了下载地址。
最简单的办法：断开公司 WiFi，用手机热点，重试。

如果需要用代理： 
export HTTPS_PROXY=http://你的代理地址:端口
# 然后重新运行安装命令
Claude Code 不支持 SOCKS 代理和 NTLM/Kerberos 认证。

6. 登录时浏览器打开了但终端一直转圈「等待认证」

原因：localhost 回调被拦截（远程桌面、虚拟机、部分防火墙）。
终端里按 C 键复制认证链接 → 粘贴到任意浏览器打开 → 完成登录 → 把浏览器显示的验证码粘贴回终端。

7. 设置 API Key 后仍提示「未认证」

原因：密钥在当前终端未生效，或与 OAuth 登录冲突。
先检查：echo $ANTHROPIC_AUTH_TOKEN 是否有输出。
如果为空，说明 export 只在另一个终端生效。在当前终端重新执行： 
export ANTHROPIC_AUTH_TOKEN=你的密钥
export ANTHROPIC_BASE_URL=你的API地址
如果之前用 claude 登录过（OAuth），旧的 ANTHROPIC_API_KEY 可能冲突： 
unset ANTHROPIC_API_KEY
# 并编辑 ~/.zshrc 删除旧的 export ANTHROPIC_API_KEY=... 行

8. 安装时提示网络超时 / Connection Refused

原因：当前网络无法访问 GitHub / npm / Anthropic 服务器。
优先级从高到低：
① 断开 WiFi，连手机热点，重试
② 如果开了 VPN，切换到全局模式
③ 如果是 Linux 服务器，检查 DNS：ping github.com
④ npm 国内镜像：npm config set registry https://registry.npmmirror.com

9. 安装脚本跑着跑着不动了（卡死）

原因：下载大文件时网络波动，或系统资源不足。
① 按 Ctrl + C 中断
② 关闭终端，重新打开
③ 重新运行安装命令（安装脚本支持断点续传，已安装的部分不会重复下载）
④ 如果反复卡死，换手机热点网络重试

10. 403 错误 /「模型不可用」

原因：账户没有该模型的访问权限，或 API 余额不足。
如果用 Anthropic 官方 API：登录 console.anthropic.com 检查账户余额和模型权限。

如果用 DeepSeek：登录 platform.deepseek.com 检查 API Key 是否有效、账户是否有余额。

在 Claude Code 里运行 /model 查看和切换可用的模型。
