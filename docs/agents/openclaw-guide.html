开始之前，确认三件事
❶ 你有一台电脑（Mac 或 Windows 都行）
❷ 电脑连着网
❸ 会复制粘贴
💡 OpenClaw 是微软开源的 AI 编程助手，支持 75+ 种 AI 模型。安装阶段不需要 API Key；首次配置或正式使用时，推荐使用 DeepSeek API Key（国内获取方便、价格便宜）。
1
打开你电脑上的「终端」
Mac 用户 — 点右上角🔍搜索图标，输入「终端」，看到黑色图标点开它。你会看到白字黑底的窗口：
终端 — zsh — 80×24
Last login: Thu May 29 14:32:11 on console
~ $
Windows 用户 — 同时按下 ⊞ 键和 R 键，输入 powershell，点确定。你会看到蓝底白字的窗口：
Windows PowerShell
Windows PowerShell
版权所有 (C) Microsoft Corporation。保留所有权利。

PS C:\Users\你的用户名>
2
复制下面这行命令，粘贴进去
先看清你是 Mac 还是 Windows，选对那一行。全选 → 复制 → 粘贴到终端窗口里。
⚠️ 重要提醒：PDF 里的长命令有时会因换行被拆成两段。如果你看到类似 @v3.0. 和下一行 7/scripts/...，说明命令被拆坏了。请优先打开交付包里的《06-一键复制命令.txt》，从里面复制完整命令。
🖥 Mac 用户 — 复制这行
curl -fsSL "https://vinnim92.github.io/agent-install-guide/i/openclaw.sh" | AGENT_INSTALL_YES=1 bash
⊞ Windows 用户 — 复制这行
irm https://vinnim92.github.io/agent-install-guide/i/openclaw.ps1 | iex
3
按下回车键，然后等着
按下键盘上的 Enter（回车键）。屏幕会开始滚动文字——这是脚本在自动工作。

你什么都不用操作。脚本会自动检测系统、安装需要的工具、装好 OpenClaw。

大约 3-5 分钟后，看到屏幕出现 ✅ 和「安装完成」就装好了。
⏳ 如果 Mac 弹窗问你要不要装「开发者工具」——点「安装」，2 分钟后会自动继续。
4
首次配置 —— 推荐 DeepSeek API Key
装好后，打开终端（或 PowerShell），运行：
openclaw onboard --auth-choice deepseek-api-key
按提示输入你的 DeepSeek API Key（在 platform.deepseek.com 注册获取，以 sk- 开头）。

验证配置：
openclaw models list --provider deepseek
启动控制面板：
openclaw dashboard
💡 OpenClaw 支持 75+ 模型提供商。DeepSeek API Key 对国内用户最友好：注册方便、价格便宜。安装阶段不需要 API Key；首次配置或正式使用时需要。
