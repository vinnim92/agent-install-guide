开始之前，确认三件事
❶ 你有一台电脑（Mac 或 Windows 都行）
❷ 电脑连着网
❸ 会复制粘贴
💡 全程不需要懂任何技术名词。跟着做就行，每一步都写好了你该干什么。
1
打开你电脑上的「终端」
Mac 用户 — 点右上角🔍搜索图标，输入「终端」，看到黑色图标点开它。你会看到白字黑底的窗口：
终端 — zsh — 80×24
Last login: Thu May 29 14:32:11 on console
~ $
Windows 用户 — 同时按下 ⊞ 键和 R 键，输入 powershell，点确定。你会看到蓝底白字的窗口：
Windows PowerShell
Windows PowerShell
版权所有 (C) Microsoft Corporation。保留所有权利。

PS C:\Users\你的用户名>
2
复制下面这行命令，粘贴进去
先看清你是 Mac 还是 Windows，选对那一行。全选 → 复制 → 粘贴到终端窗口里。
🖥 Mac 用户 — 复制这行
curl -fsSL https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.9/scripts/install-claude-code.sh | bash
⊞ Windows 用户 — 复制这行
iwr -useb https://cdn.jsdelivr.net/gh/vinnim92/agent-install-guide@v3.0.9/scripts/install-claude-code.ps1 | iex
3
按下回车键，然后等着
按下键盘上的 Enter（回车键）。屏幕会开始滚动文字——这是脚本在自动工作。

你什么都不用操作。脚本会自动检测系统、安装需要的工具、装好 Claude Code。

大约 3-5 分钟后，看到屏幕出现 ✅ 和「安装完成」就装好了。
⏳ 如果 Mac 弹窗问你要不要装「开发者工具」——点「安装」，2 分钟后会自动继续。
4
设置 API 密钥（装好了，但离能用还差这一步）
Claude Code 需要一个 API 密钥 才能连接 AI 服务器。就像手机需要 SIM 卡才能打电话一样。
你有两个选择，推荐用 DeepSeek——对国内用户来说更容易获取、更便宜、不需要翻墙。
👈 推荐
🟢 DeepSeek
① 打开浏览器 → 访问 platform.deepseek.com
② 点右上角「注册」→ 用手机号注册（和注册微信一样）
③ 登录后点左侧菜单「API Keys」
④ 点「创建 API Key」→ 复制生成的密钥（以 sk- 开头）
⑤ 打开终端，输入下面两行（换成你的密钥）：
export ANTHROPIC_AUTH_TOKEN=sk-你的密钥
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
⑥ 输入 claude 回车 —— 开始用！
💰 费用：充值即用，¥1 起充，按量扣费，很便宜
🔵 Anthropic 官方
① 打开浏览器 → 访问 console.anthropic.com
② 注册 Anthropic 账号（需要邮箱 + 海外手机号验证）
③ 进入 API Keys 页面 → 创建密钥
④ 在终端输入：
export ANTHROPIC_AUTH_TOKEN=sk-ant-你的密钥
export ANTHROPIC_BASE_URL=https://api.anthropic.com
💰 费用：需要外币信用卡，月费 $20 起（Pro 版）
🔑 API 密钥就像银行卡密码——妥善保管，不要泄露给他人。如果密钥不小心暴露了，马上去网站删除重建一个。
Claude Code 能干什么？—— Skill 让你的 AI 变身专家
Claude Code 装好之后本身是一个「通用 AI 程序员」，你可以跟它聊天、让它写代码。
但如果装上 Skill 配置包，它会变成某个领域的专家——你只需要说话，它帮你完成整个任务。
🎨
PPT 生成
「帮我做一份 8 页杂志风 PPT」→ 5 分钟后一份能上台讲的演示稿。自动排版、配色、配图。
📊
Excel 自动化
「帮我把本月销售数据做成周报」→ 自动生成图表、透视表、格式化，告别手工活。
🛠
更多场景
代码审查、项目脚手架、文档生成、数据处理……Skill 让 AI 从「能聊天」变成「能干活」。
每个 Skill 针对一个具体任务深度优化——你只需要用自然语言说出需求，AI 就会自动调用对应的 Skill 帮你完成。把你从「我要告诉 AI 怎么做」变成「我要告诉 AI 做什么」。
